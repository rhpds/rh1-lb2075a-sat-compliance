== Next Steps

This lab covered one focused SCAP profile with a single tailoring rule. There is a lot more to explore.

=== Expand Your SCAP Coverage

The SCAP Security Guide ships several profiles beyond the DISA STIG used here.
Try creating additional compliance policies against:

* *OSPP* — Protection Profile for General Purpose Operating Systems, common in government environments
* *HIPAA* — Health Insurance Portability and Accountability Act baseline for healthcare systems
* *PCI-DSS* — Payment Card Industry Data Security Standard for cardholder data environments
* *CIS* — Center for Internet Security benchmarks for broad industry hardening

Running multiple policies against the same host group gives you a full picture of your compliance posture across different regulatory frameworks.

=== Automate Remediation at Scale

In this lab you remediated a single rule on one host.
Satellite can apply Ansible remediations across large fleets using bulk remote execution jobs.
Consider:

* Running remediation jobs against host collections instead of individual hosts
* Scheduling remediation jobs to run automatically after each compliance scan
* Using Satellite's compliance reports to prioritize the highest-impact rule failures first

=== Build Custom Tailoring Files

The tailoring file in this lab enabled a single SSHD rule.
In production, your organization will need tailoring files that enable or disable dozens of rules to match your internal security policy.
The OpenSCAP documentation covers the XCCDF tailoring format, and the `oscap` command-line tool can help you generate and validate tailoring files from existing profiles.
